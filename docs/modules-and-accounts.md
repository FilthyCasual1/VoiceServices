# Modules and accounts

Optional services now use separate file packages rather than bundled feature
flags. See [Addon packages](addon-packages.md) for installation and removal,
[Core administration](core-administration.md) for account and branding controls,
and [Alpine deployment](alpine-install.md) for system-account authentication.

The permanent core is the authenticated admin/user shell. Application data is
retained on addon removal. Native phone roaming, telephony CTI, live providers and
recording remain adapter work rather than completed integrations.
